# DWF Project Artifact Roles

- **RULES** constrain how solutions are chosen when multiple implementations could satisfy accepted behavior.
- **CONTEXT** records durable project/repository facts needed to reason safely.
- **PRD** consolidates observable/product behavior for implementation.
- **SPEC** consolidates the technical implementation contract.
- **Decisions / Technical Decisions / Edge Cases** provide durable traceable accepted truth and deeper rationale/scenarios.
- **Concepts** are derived subsystem/flow mental models. Read them when Delivery points to them or when deeper understanding is useful; never let a Concept override canonical design.

The project `design/README.md` maps concrete files and local stable-ID conventions.
