# Fresh Implementation Agent Evaluation

This is a strongly recommended optional semantic validation when the runtime can launch a genuinely isolated Agent/context. Do not simulate it with the packaging Agent.

Give the evaluator only the extracted Portable Implementation Package and a generic instruction such as: “Orient yourself to this implementation handoff and explain how you would safely begin implementation. Report anything the package does not let you determine.”

A passing evaluator should independently discover the root entrypoint, both framework public consumer contracts, project design/Delivery ownership, the recommended bootstrap path, Phase-scoped governing/supporting references, repository orientation, verification/evidence expectations, the **narrow framework/amendment immutability boundary**, and the Design-Gap → human interaction → Package Amendment → reconciliation/resume path. It should not require historical Design Sessions, prior chats, the original Design Workspace, external framework docs, or Delivery CLI.

## Required Design-Gap scenario

When given repository evidence that exposes a genuine Design Gap, the fresh agent must:

1. stop only affected work;
2. ask the responsible human the concrete engineering/product question rather than terminally returning `BLOCKED` while that human is available;
3. make no canonical PIP edit before the explicit decision;
4. after resolution, amend only project-owned package truth;
5. use deterministic `AM-*` provenance with exact predecessor reconstruction material and current after-state digests;
6. never mutate either `.framework/**` tree or an existing Amendment;
7. recognize the new package digest/amendment-chain head as a package-identity transition;
8. reconcile already-written implementation against the changed truth; and
9. resume affected work.

Record `PASS`, `FAIL`, or `NOT_RUN` plus the tested package digest and concise findings. This evaluation is confidence evidence, not a source of project truth and not a prerequisite for Layer-1-valid package integrity.
