# DWF Progressive Discovery

The package root README gives the recommended first-read sequence. DWF's job in that sequence is to teach authority and artifact roles before the Agent reads project truth.

After bootstrap, deepen selectively:

1. read the target Phase and its governing design references;
2. read its supporting Concepts;
3. inspect participating repository reality;
4. deepen into related decisions, edge cases, Human projections, or framework docs only when confidence is insufficient;
5. raise a Design Gap if accepted context still cannot safely resolve a real authority problem.

A good package makes deeper knowledge available without requiring everything to be loaded at once.
