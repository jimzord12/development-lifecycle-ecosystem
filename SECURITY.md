# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability reporting/security-advisory flow when it is available for this repository. Do not disclose suspected vulnerabilities in a public issue before maintainers have had a reasonable opportunity to investigate and respond.

Include enough detail to reproduce and assess the issue, including affected versions or commits when known.

## Supported versions

Until the project begins publishing versioned packages, security fixes target the current `main` branch. A published-version support policy will be documented when releases begin.
